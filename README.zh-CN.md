# agy-capsule

[English](./README.md) | [繁體中文](./README.zh-TW.md) | **简体中文**

专为 Google Antigravity 2.x 打造的零外部依赖原生插件：直接在**输入框底栏**嵌入 **Context 占比、生成速率（`tok/s` / `TTFT`）、Prompt Cache 过期预警、7 类上下文构成占比**与**当前模型 5h／Weekly 配额**双胶囊。

## 功能特色

- **输入框底栏内嵌双胶囊（Shadow DOM 隔离）**：
  - **Context 与生成速率胶囊**：闲置时维持极简单百分比显示（配合高占用与 Cache 预警／过期图标变色），并以三段式平滑冷却呈现 `tok/s`（生成中彩色呼吸闪烁 → 完成后保留分级色 15 秒定格 → 闲置平滑退为静止灰，宽度零跳动）。
  - **动态模型配额胶囊**：监听底栏相邻模型选择器文本（自动匹配 `Gemini`、`Claude`、`Argon`、`Carbon`、`Hydrogen`、`Flash` 等配额池），实时显示对应的 `5h` 与 `Weekly` 剩余比例。
- **极简交互式上浮弹窗（悬停展开＋点击固定）**：
  - **上下文详情弹窗（~248px 紧凑卡片）**：
    - **Prompt Cache 冷却与静默快捷钮**：按最后步骤时间戳计算分钟级闲置时长（`<1m`、`1m`、`Xh Ym`；打开弹窗立即刷新并每 30 秒更新，`<3m` 正常、`3m–4m` 黄色 `~1m` 预警、`>=4m` 过期划线标记），右侧提供悬停显现的 `↻` 重扫、`EN / 简 / 繁`、`Auto / Light / Dark` 微型按钮。
    - **摘要行与 `4px` 分段进度条**：简洁显示 `已用 %` 与 `用量 / 上限`（悬停显示 `Cache / Input / Output / 剩余` 精确明细），搭配过滤亚像素碎点的 `4px` 进度条；仅在 `>=90%`、未知附件或请求错误时显示紧凑提醒。
    - **7 类精确三栏明细**：沿用 `色点＋简短分类 | % | k` 对齐节奏，严格收敛至 `100%`（系统提示、工具调用、模型回复、思考过程、用户消息、压缩摘要、附件内容；悬停显示完整说明与附件名）。
    - **极简双行生成性能**：分隔线下方纯文字呈现端到端 `tok/s` 与同色分级字样（极速／流畅／良好／偏慢）、`产出`、`首字延迟 · 总耗时` 与有效 `步数`。
  - **多模型配额弹窗**：展示所有配额分组、以 `当前` 绿点标记当前激活模型池并淡化非当前池，呈现与上下文卡统一的 `5 小时`／`每周` `4px` 线性进度条（含低额度黄／红警示、重置倒计时，并自动隐藏缺失的单窗口行如 `Argon`）。
- **9 阶段窄栏自适应折叠**：空间不足时依次折叠速率文本、次要配额、配额数字、上下文数字并优雅截断模型名称，避免与右侧控件重叠。
- **原生 Sidecar + 免改 `app.asar`**：采用无面板后台 Sidecar 与增量推送 CDP 通道，不修改客户端源码，升级后直接生效；通过文件 `mtime/size` 门控 `node:sqlite` 读取，对话闲置时零重复扫描开销。

## 安装与卸载

1. **Windows**：运行 `install.bat`（安装至 `%USERPROFILE%\.gemini\config\plugins\agy-capsule`）；卸载运行 `uninstall.bat`。
2. **macOS / Linux**：运行 `./install.sh`（安装至 `~/.gemini/config/plugins/agy-capsule`）；卸载运行 `./uninstall.sh`。
3. 在 Antigravity 的 **Plugins** 面板启用 **agy-capsule**。
