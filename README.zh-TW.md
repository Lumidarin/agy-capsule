# agy-capsule

[English](./README.md) | **繁體中文** | [简体中文](./README.zh-CN.md)

專為 Google Antigravity 2.x 打造的零外部套件依賴原生插件：直接於**輸入框底欄**內嵌 **Context 佔比、生成速率（`tok/s` / `TTFT`）、Prompt Cache 過期預警、7 類上下文構成占比**與**當前模型 5h／Weekly 配額**雙膠囊。

## 功能特色

- **輸入框底欄內嵌雙膠囊（Shadow DOM 隔離）**：
  - **Context 與生成速率膠囊**：閒置時維持極簡單百分比顯示（搭配高占用與 Cache 預警／過期圖示變色），並以三段式平滑冷卻呈現 `tok/s`（生成中彩色呼吸閃動 → 完成後保留分級色 15 秒定格 → 閒置平滑退為靜止灰，寬度零跳動）。
  - **動態模型配額膠囊**：透過 `MutationObserver` 監聽底欄相鄰模型選擇器文字（自動比對 `Gemini`、`Claude`、`Argon`、`Carbon`、`Hydrogen`、`Flash` 等配額池），即時顯示匹配的 `5h` 與 `Weekly` 剩餘百分比。
- **極簡互動式上浮彈窗（懸停展開＋點擊釘選）**：
  - **上下文詳情彈窗（~248px 緊湊卡片）**：
    - **Prompt Cache 冷卻與靜默快捷鈕**：依最後步驟時間戳計算分鐘級閒置時間（`<1m`、`1m`、`Xh Ym`；開啟彈窗即時刷新並每 30 秒更新，`<3m` 綠勾、`3m–4m` 黃色倒數 `~1m`、`>=4m` 刪除線過期標記），右側提供懸停顯現的 `↻` 重掃、`EN / 简 / 繁`、`Auto / Light / Dark` 微型按鈕。
    - **摘要列與 `4px` 分段進度條**：簡潔顯示 `已用 %` 與 `用量 / 上限`（懸停顯示 `Cache / Input / Output / 剩餘` 精確明細），搭配自動過濾次像素碎點的 `4px` 進度條；僅於 `>=90%`、未知附件或請求異常時顯示緊湊提醒列。
    - **7 類精確三欄明細**：沿用 `色點＋簡短分類 | % | k` 對齊節奏，透過最大餘額法嚴格收斂至 `100%`（系統提示、工具呼叫、模型回覆、思考過程、使用者、壓縮摘要、附件內容；懸停顯示完整說明與附件檔名）。
    - **極簡雙行生成效能**：分隔線下方純文字呈現端到端 `tok/s` 與同色分級字樣（極速／流暢／良好／偏慢）、`產出`、`首字延遲 · 總耗時` 與有效 `步數`（無多餘內嵌邊框）。
  - **多模型配額彈窗**：列出所有模型配額分組、以 `目前` 綠點標記目前選中分組並淡化非目前池，呈現與上下文卡統一的 `5 小時`／`每週` `4px` 線性進度條（含低額度黃／紅警示、即時重置倒數，並自動隱藏缺漏的單視窗列如 `Argon`）。
- **9 階段窄欄自適應收折**：底欄空間不足時依序收折速率文字、次要配額、配額數字、上下文數字、軟／硬省略模型名稱與配額膠囊，確保不與右側按鈕重疊。
- **原生 Sidecar + 免改 `app.asar`**：
  - 採無 WebUI 背景 Sidecar（`has_web_ui: false`）與單次注入、僅在 `rev` 變更時推送的 CDP 通道，不修改客戶端安裝檔，Antigravity 升級後無需重裝。
  - 採檔案 `mtime/size` 閘門的唯讀 `node:sqlite` 與 Language Server RPC 混合採集，對話閒置時零重複掃描開銷。

## 安裝與移除

1. **Windows**：雙擊或執行 `install.bat`（將插件同步至 `%USERPROFILE%\.gemini\config\plugins\agy-capsule`）；移除請執行 `uninstall.bat`。
2. **macOS / Linux**：執行 `./install.sh`（同步至 `~/.gemini/config/plugins/agy-capsule`）；移除請執行 `./uninstall.sh`。
3. 開啟 Antigravity 左側 **Plugins** 面板並啟用 **agy-capsule** 即可。
