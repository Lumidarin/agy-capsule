# agy-capsule

Real-time context window and quota capsules for the Antigravity composer footer.

## Install / update / uninstall

From the repository root, run `install.bat`, `update.bat`, or `uninstall.bat` on Windows; use `sh install.sh`, `sh update.sh`, or `sh uninstall.sh` on macOS/Linux. Update uses the local checkout, so pull the latest code first. Scripts sync this plugin folder to `~/.gemini/config/plugins/agy-capsule`; uninstall keeps preferences in `~/.gemini/config/agy-capsule/settings.json`.

Installed runtime files are checked every second. After a 1.5-second quiet period, the plugin cleans up and exits for AGY to restart it and reconnect open sidebars. Copy batches are protected by an update marker. Upgrading from a version without this watcher requires one manual restart. Manual folder installation is still supported. Reload open pages after uninstall if injected UI remains.

## Features
- **Turn metrics**: An independent, default-on block in the context popover and sidebar sums recorded model attempts (including retries), cached/uncached input, response/tool-call instructions and thinking since the latest sent user message. Queueing is included in wall-clock elapsed time; known executor/step endings freeze the timer. Missing usage, associations or cancellation timestamps stay unknown, with recorded subtotals in tooltips. Existing context allocations and latest-request metrics remain unchanged.
- **Independent appearance controls**: Choose panel height, density, quota indicator and category marker separately. The sidebar and web page share these controls, without preset management or settings import/export.
- **Sidebar Settings**: Switch between statistics and settings at the top. Select display language (English by default), independent appearance options and optional active-model highlighting; theme always follows the app. Settings language is selected separately (Simplified Chinese by default). Compact spacing, ring quotas, square markers and no highlighting are the defaults; four-category telemetry is unchanged. Request and turn statistics have separate settings groups; step-record counts are not included. Click capsules to pin popovers with a selected background; click again, outside, or press Escape to close. Presentation inspired by [z21100644's PR #1](https://github.com/Lumidarin/agy-capsule/pull/1), without its seven-category estimates or attachment scanner.
- **Ground-Truth Telemetry**: Reads exact API token counts (`uncached_input`, `cached_input`, `output_tokens`, `thinking_tokens`) from the local conversation database (`%USERPROFILE%\.gemini\antigravity\conversations\<id>.db` on Windows, `~/.gemini/antigravity/conversations/<id>.db` on macOS/Linux), and resolves each session's active context limit dynamically from model metadata (`0 / --` before the first turn).
- **Compaction-Aware Breakdown**: Uses the latest billed turn (`uncached_input + cached_input`) for active context usage and resets breakdown accumulation (`Turn0`, `Read`, `Think`, `Write`) at the latest compaction checkpoint (`step_type = 23` or token-drop fallback).
- **Composer Dual Capsules & Popovers**: Displays live context percentage and matched model quotas (`Gemini`, `Claude`, `Argon`, `Carbon`) directly in the composer footer, with hover popovers for token breakdown, 3m/4m cache expiry estimates, and 5h/Weekly reset countdowns.
- **4-Level Narrow Fallback**: Progressively degrades when the composer narrows (hide Weekly quota or `--%` placeholder → keep 5h icon → keep context & quota icons → ellipsis-truncate the model selector) to preserve hover access without overlap.
- **Local Font Fallbacks & Theme Sync**: Prefers Source Han Sans and falls back to the system UI font (no downloads), while adapting to light/dark themes via host CSS variables.
