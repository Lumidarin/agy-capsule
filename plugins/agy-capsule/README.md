# agy-capsule (v1.0.0)

Composer footer dual capsules for Google Antigravity 2.x:

- Context window occupancy (`%`), `4px` segmented track, and 7-category 3-tier breakdown
- 3-stage smooth generation speed pill (live pulse -> 15s tier tint -> static muted gray) with `TTFT`, duration & output tokens
- Minute-granular prompt cache TTL status (`<3m` warm / `3m` warning / `4m+` expired, on-open + 30s refresh)
- Active model-matched `5h` and `Weekly` quota capsule + unified `4px` linear-bar quota popover
- `EN` / `简体中文` / `繁體中文` and `Auto` / `Light` / `Dark` theme switching
